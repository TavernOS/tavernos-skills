# Competitive Analysis

## Analysis framework
For each competitor:
- **Overview** — what they do, who they serve, size/stage
- **Strengths** — what they do well
- **Weaknesses** — where they fall short
- **Positioning** — how they describe themselves
- **Pricing** — if available
- **Recent moves** — product launches, funding, partnerships, news

## Comparison output
Build a comparison matrix across:
- Target customer
- Core value proposition
- Key features
- Pricing model
- Differentiators

## Synthesis
End with:
- **Market gap**: What's underserved?
- **Our edge**: Where do we win?
- **Our risk**: Where are we vulnerable?
- **Watch list**: Which competitor moves matter most?

## Guidelines
- Use public information only — don't guess at private data
- Flag when information is likely outdated
- Chain to Frasier for strategic positioning recommendations
- Chain to Woody to turn analysis into a written brief
